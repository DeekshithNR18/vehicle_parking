# veh_parking1 (Car Parking Management System)

A full-stack, multi-user Smart Society Parking application built with React, Node.js, Express, and SQLite.

## Features
- **Role-Based Access Control:** Separate dashboards for Residents, Security Guards, and Admins.
- **Live Parking Map:** Interactive grid with real-time slot availability.
- **Pre-Booking:** Date & time selection for future parking.
- **Digital Wallet:** Top-up and auto-deduction for bookings.
- **Visitor Passes:** Generate QR codes for guests.
- **Maintenance Ticketing:** File complaints and get replies from the Admin.
- **SOS Emergency:** Panic button that instantly alerts the Admin/Guard.
- **Offline Mode:** Queue bookings when disconnected and auto-sync when online.
- **PWA Ready:** Installable on Android, iOS, and Desktop.

## Tech Stack
- **Frontend:** React, Vite, TailwindCSS, Framer Motion, Leaflet (Maps), Recharts (Analytics).
- **Backend:** Node.js, Express.js, JWT (Authentication), BcryptJS (Hashing).
- **Database:** SQLite (better-sqlite3).
